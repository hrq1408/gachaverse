Build your team around what the Agents can do together. Open each Agent’s Additional Ability description and read the full activation requirement. Sharing an Attribute or Faction can help in some cases. Use the individual description to check what that Agent requires.

## Three checks before you start

1. Choose who can keep up the pressure while the target is moving.
2. Decide who sets up the opening for the main hit or the next application of an effect.
3. Check that your chosen order lets you meet the Additional Ability requirement, make good use of each Agent’s time on the field, and set up the next swap.

**Example.** You’ve planned a sequence to deal most of your damage once the target is stunned. Test it by setting up the opening first, then swapping and using your main attack. If the window closes before the last hit, try using slower abilities before the opening. Compare both sequences against the same target.

## Start with the in-game recommendations

When a mode offers a team composition guide, use it to compare roles. Official notes also record changes to Additional Abilities. Before investing in another Agent, check in-game that the suggested lineup activates the effect you want.

HoYoverse’s notes document different requirements for Agents’ Additional Abilities. When comparing Agents, open each description and summarize the requirement in one short line. That makes it easier to spot when swapping an Agent out changes the lineup that enabled the effect.
