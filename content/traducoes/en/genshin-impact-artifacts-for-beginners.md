Start with the Artifacts you already own. Check the main stat and read the set bonus in the game. A piece that helps a character do its job can be worth using while you work toward a better set.

## Compare the main stat and the set effect

| Check | Ask before spending materials |
| --- | --- |
| Main stat | Does it help the team’s damage, energy, or survival? |
| Set bonus | Can the team meet the reaction or ability condition in the description? |
| Upgrade budget | Does this piece fix a bottleneck now, or is it likely to be replaced after the next unlock? |

## Test one change at a time

If a rotation stalls because the Elemental Burst is not ready, compare a piece that helps with energy against one focused on damage. Test against the same enemy with the same team. If both work, save further upgrades for the piece that remains useful in other fights.

Artifact acquisition and upgrades involve random outcomes. Read the effect description, check that it activates in combat, and avoid spending materials just to chase one substat before you know what the character needs.
