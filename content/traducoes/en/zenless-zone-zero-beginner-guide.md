Follow the main story while its missions are available. When you need a next step, open the Beginner Guide from the right side of the main screen. The feature announcement describes upgrade guidance and handbook missions. Check both to see which Agent upgrade or reward is within reach.

## Check what is blocking you

| Situation | What to check |
| --- | --- |
| An activity lists an Inter-Knot requirement | Check whether it also requires a story chapter. Progress on one requirement does not complete the other. |
| You can enter a challenge but keep losing | Review the equipment and upgrades on the Agents you take into the fight. |
| An event has a deadline | Confirm access and read the closing time for your server. |

## Practise switches before using more materials

Pick a fight you can repeat. Test which Agent opens the fight, which keeps the rotation going, and which finishes the damage window. If a follow-up attack does not trigger, read the ability conditions on the Agent's profile.

For example, if an event asks for a chapter and an Inter-Knot level, finish the specified mission and check the level again before retrying.
